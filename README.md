# Support Hub — AI Ticket Triage

Міні веб-додаток для автоматизації першої лінії служби підтримки. Забезпечує збереження вхідних звернень, структурований аналіз за допомогою LLM, визначення терміновості та генерацію контекстної відповіді клієнту.

## Стек технологій
- **Фреймворк**: Next.js 14+ (App Router, Server Actions, TypeScript)
- **Стилізація**: Tailwind CSS, Lucide Icons
- **База даних**: PostgreSQL (Neon Serverless) + Prisma ORM
- **ШІ-рушій**: Vercel AI SDK (`generateObject`) + Gemini 2.5 Flash
- **Валідація схеми**: Zod
- **Деплой**: Vercel

## Ключові можливості
- Збереження клієнтських звернень у хмарну PostgreSQL базу.
- Структурована класифікація за допомогою AI:
  - **Пріоритет**: низький / середній / високий
  - **Категорія**: автоматичне тегування тематики
  - **Стислий підсумок**: суть проблеми рівно в одне речення
  - **Чернетка відповіді**: контекстний проект повідомлення для оператора
- Швидке копіювання згенерованої відповіді в буфер обміну.
- Тестові шаблони в 1 клік для демонстрації роботи.
